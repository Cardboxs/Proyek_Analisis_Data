# 🚲 Proyek Analisis Data: Bike Sharing Dashboard

## Setup Environment- venv
```bash
# 1. Masuk ke direktori utama proyek
cd Proyek_Analisis_Data

# 2. Membuat virtual environment baru bernama 'venv'
python -m venv venv

# 3. Mengaktifkan virtual environment
# Jika menggunakan Windows:
venv\Scripts\activate
# Jika menggunakan Mac/Linux:
source venv/bin/activate

# 4. Instalasi pustaka yang dibutuhkan
pip install -r requirements.txt
```
## Run streamlit app
```bash
# 1. Masuk ke dalam folder dashboard
cd dashboard

# 2. Jalankan aplikasi streamlit
streamlit run dashboard.py
